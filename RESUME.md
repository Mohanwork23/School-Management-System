# Resume Bullet Points for School Management System

- Designed and built a **Spring Boot 3** backend for a School Management System with support for Admin, Teacher, Student, and Parent roles.
- Implemented **JWT-based stateless authentication** and **Spring Security** role-based access control for campus operations.
- Developed modules for **attendance tracking**, **fee management**, **timetables**, **exam scheduling**, **results reporting**, **assignments**, and **parent portal access**.
- Added **Spring Data JPA** with MySQL persistence, **Flyway** database migrations, and **REST API documentation** using Springdoc OpenAPI.
- Configured **GitHub Actions CI/CD** with automated Maven tests, Docker image publishing to GHCR, and Trivy container security scanning.
- Containerized the application with **Docker** and enabled local demo orchestration through **Docker Compose**.
- Implemented centralized exception handling, file upload support, and OTP-based email verification for secure user workflows.
